# Дерево розбиття тестових варіантів для MyNotes App

## Структура тестування

### 1. Аутентифікація користувача

#### AC-001: Відображення екрану входу для неаутентифікованих користувачів
- **Вхідні дані**: Додаток запущено, користувач не аутентифікований
- **Очікуваний результат**: Відображається екран входу
- **Тестовий метод**: `testUnauthenticatedUserSeesSignInScreen()`

#### AC-002: Успішний вхід через Google
- **Вхідні дані**: Користувач на екрані входу, дійсні облікові дані Google
- **Очікуваний результат**: Перехід до списку нотаток, стан аутентифікації = Success
- **Тестовий метод**: `testSuccessfulGoogleSignIn()`

---

### 2. Керування нотатками (Online режим)

#### AC-003: Створення нотатки (Online)
- **Вхідні дані**: 
  - Користувач аутентифікований
  - Інтернет-з'єднання доступне
  - Користувач натискає кнопку "+"
- **Очікуваний результат**: 
  - Нотатка створюється з унікальним ID
  - Нотатка зберігається локально (Room)
  - Нотатка синхронізується з Firebase
  - Нотатка з'являється у списку
- **Тестовий метод**: `testCreateNoteOnline()`

#### AC-004: Редагування нотатки (Online)
- **Вхідні дані**: 
  - Існуюча нотатка
  - Інтернет-з'єднання доступне
  - Користувач редагує title та content
  - Користувач натискає "✓"
- **Очікуваний результат**: 
  - Зміни зберігаються локально
  - Зміни синхронізуються з Firebase
  - Оновлена нотатка відображається у списку
- **Тестовий метод**: `testUpdateNoteOnline()`

#### AC-005: Видалення нотатки (Online)
- **Вхідні дані**: 
  - Існуюча нотатка
  - Інтернет-з'єднання доступне
  - Користувач натискає кнопку видалення
- **Очікуваний результат**: 
  - Нотатка видаляється з Room
  - Нотатка видаляється з Firebase
  - Нотатка зникає зі списку
- **Тестовий метод**: `testDeleteNoteOnline()`

---

### 3. Керування нотатками (Offline режим)

#### AC-006: Створення нотатки (Offline)
- **Вхідні дані**: 
  - Користувач аутентифікований
  - Інтернет-з'єднання недоступне
  - Користувач натискає кнопку "+"
- **Очікуваний результат**: 
  - Нотатка створюється з унікальним ID
  - Нотатка зберігається локально (Room)
  - Нотатка з'являється у списку
  - При поверненні з'єднання - синхронізація з Firebase
- **Тестовий метод**: `testCreateNoteOffline()`

#### AC-007: Редагування нотатки (Offline)
- **Вхідні дані**: 
  - Існуюча нотатка
  - Інтернет-з'єднання недоступне
  - Користувач редагує та натискає "✓"
- **Очікуваний результат**: 
  - Зміни зберігаються локально
  - Оновлена нотатка відображається у списку
  - При поверненні з'єднання - синхронізація з Firebase
- **Тестовий метод**: `testUpdateNoteOffline()`

---

### 4. Синхронізація даних (Real-time)

#### AC-008: Синхронізація створення даних
- **Вхідні дані**: 
  - Користувач online
  - Нотатка створюється
- **Очікуваний результат**: 
  - Real-time listener отримує оновлення
  - Локальна база оновлюється
  - UI оновлюється автоматично
- **Тестовий метод**: `testRealtimeSyncOnCreate()`

#### AC-009: Синхронізація редагування даних
- **Вхідні дані**: 
  - Користувач online
  - Нотатка редагується
- **Очікуваний результат**: 
  - Real-time listener отримує оновлення
  - Локальна база оновлюється
  - UI показує актуальні зміни
- **Тестовий метод**: `testRealtimeSyncOnUpdate()`

#### AC-010: Синхронізація видалення даних
- **Вхідні дані**: 
  - Користувач online
  - Нотатка видаляється
- **Очікуваний результат**: 
  - Real-time listener отримує оновлення
  - Нотатка видаляється з локальної бази
  - UI оновлюється, нотатка зникає
- **Тестовий метод**: `testRealtimeSyncOnDelete()`

## Граничні значення та винятки

### Тестування валідації даних
- Порожній title та content
- Дуже довгий title (>1000 символів)
- Дуже довгий content (>10000 символів)
- Спеціальні символи у title та content

### Тестування помилок
- Помилка Firebase аутентифікації
- Помилка мережі під час синхронізації
- Конфлікт даних при синхронізації
- Переповнення локальної бази даних
